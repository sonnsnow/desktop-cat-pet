# 桌面宠物猫 · 设计文档

> 日期：2026-10-28
> 状态：待审阅

## 1. 概述

一个 Android 悬浮窗桌面宠物应用。一只白色长毛、蓝眼睛的猫咪浮在所有 App 之上，点击它弹出今日任务面板（每天读一段话 17 遍），记录完成进度。

## 2. 平台与技术栈

- **平台**：Android（minSdk 24 / Android 7.0）
- **语言**：Kotlin
- **UI 框架**：Jetpack Compose
- **构建**：Gradle (Kotlin DSL)
- **数据存储**：DataStore Preferences（任务进度、宠物位置、设置）

## 3. 功能清单

### 3.1 悬浮窗宠物
- 猫咪以悬浮窗形式显示在所有应用之上
- 默认显示在屏幕右侧中部
- 支持拖动：长按拖动到任意位置，松手自动吸附到最近的屏幕左/右边缘
- 待机动画：缓慢呼吸缩放 + 偶尔眨眼
- 双击猫咪：快速完成一遍任务（不弹面板，直接 +1）
- 闲置打瞌睡：超过 2 小时无任何互动，猫咪进入睡眠状态（闭眼 + Zzz 动画），有新互动时唤醒
- 夜间模式（22:00 - 07:00）：猫咪透明度降为 50%，减少视觉干扰

### 3.2 任务面板
- 点击猫咪弹出任务面板
- 显示当前任务：「读一段话」
- 显示今日完成进度：X / 17
- 进度条可视化
- 「+1 完成一遍」按钮：点击后进度 +1
- 关闭按钮：收起面板
- 点击面板外区域：自动收起面板
- 完成全部 17 遍后：猫咪播放开心蹦跳动画，面板显示「今日任务已完成 🎉」
- 每日 00:00 自动重置进度为 0

### 3.3 任务配置（可选，MVP 后扩展）
- 任务名称可编辑（默认「读一段话」）
- 每日目标次数可编辑（默认 17）
- 当前 MVP 版本硬编码为「读一段话 / 17 遍」

### 3.4 保活
- 前台服务保活，显示常驻通知
- 通知可点击打开应用主界面
- 通知渠道：「桌面宠物」

### 3.5 权限
- `SYSTEM_ALERT_WINDOW`：悬浮窗权限
- `FOREGROUND_SERVICE`：前台服务
- `POST_NOTIFICATIONS`（Android 13+）：通知权限

## 5. 组件详细设计

### 5.1 PetService
- `onCreate`：初始化 FloatingPetManager，启动前台通知
- `onStartCommand`：显示悬浮窗
- `onDestroy`：移除悬浮窗，取消通知
- 使用 `WorkManager` 或 `AlarmManager` 调度每日 00:00 重置任务进度

### 5.2 FloatingPetManager
- `show()`：通过 `WindowManager.addView()` 添加 PetView，类型为 `TYPE_APPLICATION_OVERLAY`
- `hide()`：`WindowManager.removeView()`
- `updatePosition(x, y)`：更新 `LayoutParams`
- 拖动逻辑：
  - `onTouchEvent` 监听 `ACTION_DOWN/MOVE/UP`
  - DOWN 时记录起始位置和按下时间
  - 移动距离 > 阈值且时间 > 长按阈值 → 进入拖动模式
  - UP 时：若未拖动（短按）→ 触发点击事件；若拖动 → 计算最近边缘并平滑吸附
- 位置持久化：松手后保存 x/y 到 DataStore，下次启动恢复

### 5.3 PetView
- ComposeView，内容为猫咪图片
- 动画：
  - 呼吸：`animateFloatAsState` 实现 1.0 → 1.05 缩放循环（3s）
  - 眨眼：每 5 秒执行一次快速 Y 轴缩放（scaleY 1.0 → 0.1 → 1.0，总时长 150ms）模拟闭眼，无需额外图片资源
- 手势：
  - 单击 → 显示 TaskPanel
  - 双击 → 直接 +1 完成一遍（不弹面板），播放轻微弹跳反馈
  - 长按 → 拖动
- 闲置状态：
  - 记录最后互动时间，超过 2 小时 → 切换到睡眠状态（scaleY 压缩模拟闭眼 + 显示 Zzz 文字）
  - 任何互动（点击/拖动）唤醒
- 夜间模式：根据当前时间设置 `alpha = 0.5f`

### 5.4 TaskPanel
- 悬浮窗形式显示在猫咪附近（优先显示在猫咪左侧/右侧，避免超出屏幕）
- 内容：
  - 猫咪图标 + 任务名称
  - 进度文字：`已完成 X / 17`
  - 进度条：`X / 17` 百分比
  - 「+1 完成一遍」按钮
  - 「✕」关闭按钮
  - 完成时显示「今日任务已完成 🎉」
- 点击 +1：调用 `TaskRepository.increment()`，更新 UI
- 点击关闭：移除面板 View
- 点击面板外区域：在猫咪 View 上监听 `ACTION_OUTSIDE` 或在面板外部添加透明全屏层，点击后移除面板

### 5.5 TaskRepository
- DataStore 存储：
  - `task_progress`：Int，今日完成次数
  - `last_reset_date`：String，上次重置日期（yyyy-MM-dd）
  - `task_name`：String，任务名称（默认「读一段话」）
  - `task_target`：Int，目标次数（默认 17）
  - `pet_x` / `pet_y`：Int，宠物位置
  - `last_interaction_time`：Long，最后互动时间戳（用于闲置打瞌睡判断）
- `getProgress()`：读取进度，若日期已变则先重置
- `increment()`：进度 +1，持久化
- `resetIfNeeded()`：比较 `last_reset_date` 与今天，不同则重置为 0
- 每日重置由 `WorkManager` 的 `DailyResetWorker` 在 00:00 触发

## 6. 数据流

```
用户点击 +1
  → TaskPanel 调用 TaskRepository.increment()
  → TaskRepository 更新 DataStore
  → DataStore Flow 发射新值
  → TaskPanel 收集 Flow，更新进度条和文字
  → 若进度 == target，触发 PetView 播放开心动画
```

## 7. 资源

- 猫咪图片：`cat_pet_v4.jpg`（白色长毛、蓝眼睛、高光）
- 存放位置：`app/src/main/res/drawable/`
- 尺寸：512x512，悬浮窗显示时缩放到 90dp

## 8. 错误处理

- 悬浮窗权限未授予：引导用户到设置页开启，不启动服务
- 数据读取失败：进度默认 0，不崩溃
- 拖动越界：限制在屏幕范围内（考虑状态栏/导航栏高度）

## 9. 测试策略

- 手动测试为主（个人项目）：
  - 权限引导流程
  - 悬浮窗显示/隐藏
  - 拖动 + 边缘吸附
  - 点击弹出任务面板
  - +1 计数 + 进度条
  - 完成 17 次后的动画
  - 跨日重置（可手动修改系统时间验证）
  - 夜间模式透明度
- 单元测试：TaskRepository 的重置逻辑

## 10. MVP 范围

**包含：**
- 悬浮窗猫咪 + 呼吸动画
- 拖动 + 边缘吸附
- 点击弹出任务面板
- +1 计数 + 进度条
- 完成动画
- 每日重置
- 夜间半透明
- 前台服务保活

**不包含（后续迭代）：**
- 任务名称/次数可配置
- 多任务支持
- 统计图表
- 多种宠物状态表情
- 喂食/互动小游戏
